# Чатометр

Дашборд для Telegram JSON-експортів. Він не містить чатів: виберіть власний `result.json` у браузері, і вся аналітика виконається локально, без передавання повідомлень на сервер.

Запуск з кореня проєкту:

```powershell
python -m http.server 8000
```

Відкрийте `http://localhost:8000/dist/`. Щоб проаналізувати інший чат, натисніть «Завантажити result.json» і виберіть JSON з Telegram Desktop export. Жодні повідомлення нікуди не відправляються.
